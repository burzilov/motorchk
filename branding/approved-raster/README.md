# Motorchk CMS — утверждённые растровые материалы

Использовать только PNG из delivery для интерфейса. Горизонтальный вариант — финальный, с лапками на baseline; компактный вариант утверждён отдельно.

Оригиналы JPG скопированы побайтно, без перекодирования. Это имеющиеся исходные растровые генерации, не векторные мастер-файлы и не скрытые рендеры большего разрешения. Утверждённые PNG-компоновки также скопированы побайтно без изменений. Их размеры отражают монтаж и масштабирование исходных компонентов, а не дополнительную детализацию исходника.

Отвергнутые SVG и их рендеры НЕ ИСПОЛЬЗОВАТЬ. В этом пакете их нет. Работа с SVG прекращена.

components содержит выбранные компоненты, заново обрезанные из исходных JPG и сохранённые в PNG без последующего масштабирования. Исходный JPG остаётся отдельно. montage.py документирует параметры ранее выполненного монтажа; для интеграции брать существующие утверждённые PNG, не пересобирать без необходимости.

Белый фон оставлен как в утверждённых версиях. Прозрачность и векторизация не выполнялись. Репозитории, WSL и админка этим действием не изменялись.
