# Motorchk CMS — утверждённые растровые материалы

В интерфейсе используются PNG из `transparent-2026-11-12/`, скопированные побайтно в `assets/brand/`. Фон прозрачный. SVG не используются. Заново эти файлы не собираются: `extract2.py` и `build.py` только фиксируют, как PNG были получены.

Прежняя поставка с белым фоном остаётся на месте (`delivery/`, `components/`, `originals/`, `montage.py`). Её файлы не удаляются и в runtime больше не копируются.

## Прежняя поставка (белый фон)

Оригиналы JPG скопированы побайтно, без перекодирования. Это имеющиеся исходные растровые генерации, не векторные мастер-файлы и не скрытые рендеры большего разрешения. PNG-компоновки той поставки тоже скопированы побайтно. Их размеры отражают монтаж и масштабирование исходных компонентов, а не дополнительную детализацию исходника.

Отвергнутые SVG и их рендеры НЕ ИСПОЛЬЗОВАТЬ. В этом пакете их нет. Работа с SVG прекращена.

`components/` содержит выбранные компоненты, заново обрезанные из исходных JPG и сохранённые в PNG без последующего масштабирования. Исходный JPG остаётся отдельно. `montage.py` документирует параметры ранее выполненного монтажа.
